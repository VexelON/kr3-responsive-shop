## Адаптивные решения

В ходе работы были реализованы следующие решения:

- **Подключение стилей:** на всех страницах подключен отдельный файл `responsive.css` (строго после `style.css`).
- **Подход Mobile First:** базовые стили написаны для мобильных устройств, расширение происходит через медиазапросы `min-width`.
- **Мобильная навигация (бургер-меню):** реализована кнопка с иконкой, которая скрывается на десктопе. Для доступности используются атрибуты `aria-expanded` и `aria-controls`.
- **Сетки (CSS Grid):** 
  - Карточки товаров перестраиваются из **1 колонки** на мобильном в **2** на планшете и **3** на десктопе.
  - Каталог с фильтрами на мобильном идет в одну колонку, а на десктопе фильтры уходят влево.
- **Responsive Images:** используются атрибуты `srcset` и `sizes` для карточек товаров. Подготовлены уменьшенные копии изображений (480w, 960w) для оптимизации загрузки на мобильных устройствах. Также добавлены атрибуты `width`, `height` и `loading="lazy"`.
- **Адаптивные формы:** на мобильных устройствах элементы форм и кнопки выстраиваются в одну колонку и занимают 100% ширины.
- **Адаптивные таблицы:** на мобильном экране таблица характеристик товара преобразуется в карточный вид с подписями через `data-label`. На десктопе возвращается классический табличный вид.
- **Отсутствие горизонтального скролла:** проверено на ширинах 360px, 430px, 768px, 1024px и 1440px.

## Доступность (A11y)

- **Skip-link:** добавлена ссылка «Перейти к основному содержимому» для пользователей клавиатуры на всех страницах.
- **Семантика:** добавлен `id="main-content"` к тегу `<main>`. На каждой странице соблюдается иерархия заголовков (один `h1`), используются теги `<nav>`, `<header>`, `<footer>`.
- **Видимый фокус:** проведена проверка и настройка фокуса на всех интерактивных элементах (кнопки, ссылки, поля ввода, бургер-меню).
- **Формы:** проверены все `label` у полей формы (связаны через `for` и `id`).
- **Изображения:** проверены осмысленные `alt` у всех изображений.
